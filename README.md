# VTA-RL-Training

## paper link
Link: https://openreview.net/forum?id=pfP2LIiH0A

## train.py
Using TRL's GRPOTrainer for CPU testing
1. Loads json dataset (created by create_test_data.py script) and converts it into HuggingFace Dataset
2. Initialize reward function with cluster data path (created by create_test_data.py) and epsilon (privacy element from the paper).
3. Create training arguments, used the default numbers generated by Claude Code with max steps as 5 and per device train size as 2 for CPU
4. Call the trainer.train() to train the model. The model output will be in the /output folder. 

## student_simulator.py
- StyleMockEncoder: Hash based encoding generated by Claude for testing
- DPStyleReward: 
Initializing parameters: epsilon: smaller epsilon, stronger privacy and more noise, clip threshold: to disallow the model to reproduce the exact writing style, number of steps, delta (taken from the paper).
- Reward function: The logic follows the paper's logic where you get embed the generated text from the model and get the sample embeddings from the cluster. Computes the cosine probability (np.dot()) since create_test_data normalized embedding to 1. Add noise to the total similarity, and calculates reward for that text. 

## create_test_data.py
Generating test cluster data file and json file to test training pipeline. The json data is in the following format for GRPOTrainer:

<pre> ```json { "prompt": [ { "role": "user", "content": "prompt_text" } ], "cluster_id": int } ``` </pre>
